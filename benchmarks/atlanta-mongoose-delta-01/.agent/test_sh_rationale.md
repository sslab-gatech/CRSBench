# Test Script Rationale for atlanta-mongoose-delta-01

## Project Overview
- **Project**: Mongoose web server library (C/C++)
- **Repository**: https://github.com/cesanta/mongoose
- **Test Framework**: Custom unit test framework using ASSERT macros

## Test Structure Analysis

### Existing Test Suite
The project has a comprehensive unit test suite in `test/unit_test.c`:
- Contains ~95,000 lines of unit tests
- Tests all major components: HTTP, WebSocket, DNS, MQTT, TLS, JSON, etc.
- Main function calls individual test functions (e.g., `test_json()`, `test_http_parse()`, etc.)
- Uses custom ASSERT macro that aborts on failure

### Build System
The Makefile provides a `test` target:
```makefile
test: Makefile mongoose.h $(SRCS)
    $(CC) $(SRCS) $(CFLAGS) $(LDFLAGS) -o unit_test
    ASAN_OPTIONS=$(ASAN_OPTIONS) $(RUN) ./unit_test
```

Where `SRCS = mongoose.c test/unit_test.c test/packed_fs.c`

### Dependencies
- `test/packed_fs.c` must be generated before building tests
- Generated by compiling and running `test/pack.c` on sample files
- Required for file system testing features

## Test Script Design

### Approach
1. **Generate packed_fs.c**: Compile pack.c and run it to generate the required dependency
2. **Build unit_test**: Compile mongoose.c, unit_test.c, and packed_fs.c with appropriate flags
3. **Run tests**: Execute the unit_test binary, which runs all test functions

### Environment Variables Used
- `$SRC`: Source directory (OSS-Fuzz standard)
- `$CC`: C compiler with instrumentation (ASAN enabled)
- `$CFLAGS`: Compiler flags with sanitizers

### Compilation Flags
Based on Makefile defaults:
- `-DMG_MAX_HTTP_HEADERS=7`: Configuration for HTTP headers
- `-DMG_ENABLE_LINES`: Enable line number tracking
- `-DMG_ENABLE_PACKED_FS=1`: Enable packed filesystem support
- `-DMG_ENABLE_SSI=1`: Enable Server Side Includes
- `-DMG_ENABLE_IPV6=1`: Enable IPv6 support
- `-I.` and `-Isrc`: Include paths

### Test Verification
The test suite:
- Prints "SUCCESS. Total tests: N" on successful completion
- Aborts immediately on any ASSERT failure
- Returns EXIT_SUCCESS (0) on complete success

## Script Execution Flow
1. Change to mongoose source directory
2. Generate packed_fs.c dependency
3. Compile unit_test binary with all required flags
4. Run unit_test binary
5. Print success message

## Testing Results
- ✅ Script successfully builds and runs all unit tests
- ✅ Exit code 0 indicates all tests passed
- ✅ Tests cover all major mongoose functionality
